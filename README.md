# SBE LLM Center

Центральный LLM-сервис для плагинов системы SBE. Хранит только `apiUrl` и API-ключ
(в защищённом хранилище Obsidian). Модели, промты и контекст передаёт плагин-потребитель.

## Возможности

- Единая настройка API-ключа для всех SBE-плагинов (например, «Мастер презентаций»).
- Сервис публикуется в мост `window.SBE` как `sbe-llm`: `complete`, `completeJson`, `ask`.
- Ретраи с бэкффом (429/504), клиентский таймаут 180 с, извлечение JSON с повтором.
- UI на русском языке.

## Настройка

Откройте **Настройки → Плагины сообщества → SBE LLM Center**:

1. URL API (по умолчанию `https://ask.chadgpt.ru/api/v1/chat/completions`).
2. API-ключ (password-поле; пустое значение — без изменений).
3. Кнопка «Проверить» — статус конфигурации.

## Для разработчиков

Сервис получают через `getService('sbe-llm')` (sbe-core). Сигнатуры — в
`sbe-core/src/types.ts` (`SbeLlmApi`).
